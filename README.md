# Smart Calculator

A responsive calculator with keyboard support and a dark interface.

## Features
- Addition, subtraction, multiplication, division, and percentage
- Keyboard support
- Clear and delete controls

## Requirements
A modern web browser. No build tools required.

## Setup
1. Open `index.html` in your browser.
2. Edit the files in VS Code.
3. Commit the folder to GitHub.

## Notes
- This project is an educational mini-project.
- Change demo credentials and configuration before using it with real data.
- Never commit passwords, API keys, or private credentials to GitHub.
